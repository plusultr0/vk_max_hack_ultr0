# Changelog 0.9.12

## Пользовательский интерфейс

- Полностью переработана визуальная система mini-app в светлой стилистике: тёплый фон, тёмный текст, винный акцент, Manrope/Oswald.
- Сохранены только три основных пользовательских раздела: «Проверка», «Изменения», «Мой бизнес».
- Карточки получили более явную визуальную иерархию: статус → название → короткое объяснение → один следующий шаг.
- «Документы и настройки» переименованы в «Документы и важные настройки» и оформлены как отдельный быстрый вход в checklist.
- Профиль из восьми вопросов разбит на три смысловые группы; каждый вопрос пронумерован и содержит короткую подсказку.
- Уточнены подписи фильтров, источников, причин результата и редактирования ответов; убраны технически звучащие формулировки вроде «дата проверки разметки правила».
- Убрана sticky save-bar, которая могла перекрывать поля на длинной форме.
- Mobile bottom navigation остаётся одной строкой из трёх пунктов; touch targets не меньше 44 px.

## Первый запуск

- PostgreSQL healthcheck больше не полагается только на `pg_isready`.
- Compose ждёт успешный `SELECT 1` именно в `POSTGRES_DB`, что устраняет race первого clean start между `CREATE DATABASE` и контейнером `migrate`.

## Проверки в среде подготовки

- `node scripts/test-core-offline.mjs`: 88/88 passed.
- Синтаксическая транспиляция: 98 TS/TSX файлов, 0 ошибок.
- Chromium layout: список, деталь, документы, профиль × 375/768/1440 px = 12/12 passed.
- `.env` и `seed/v1/legal-rules.json` не изменены.

Полный Docker acceptance, реальный React browser regression, live GigaChat и MAX выполняются отдельно.
