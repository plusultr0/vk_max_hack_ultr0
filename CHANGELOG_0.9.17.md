# 0.9.17 — onboarding and requirement UX follow-up

## Что изменилось

- «Мой бизнес» превращён в одну последовательность из 8 вопросов: удалены eyebrow, групповые секции и старый progress track.
- Короткое описание первого экрана оставлено в требуемом виде: `Всего 8 коротких вопросов о том, как бизнес работает сейчас.`
- Пояснение о назначении ответов отделяется одной линией сверху и одной снизу; разделители между вопросами получили нормальный вертикальный отступ.
- География расширена без миграции схемы: «По всей России», «Россия и СНГ» или произвольный регион/охват. Старые строковые значения `region` остаются совместимыми.
- Объект УСН не добавлялся как отдельный профильный факт, поскольку текущие 37 правил не используют «Доходы»/«Доходы минус расходы» как условие применимости; подсказка это объясняет пользователю.
- Пользовательская навигация и список переименованы с «Проверка/Проверки» на «Требования»; удалён большой disclaimer с главного списка.
- В карточках с dynamic facts убран вторичный текст «Ответьте на то, что знаете сейчас», счётчик вопроса больше не имеет leading zero.
- Для RUB-полей число форматируется пробелами во время ввода (`35000000` → `35 000 000`), а backend получает числовое значение через существующий parser.
- Блок причины `not_applicable` больше не подставляет generic summary правила о недостающих данных.
- НДС action start-2026 прямо называет дату `1 января 2026 года`; для threshold-during-2026 используется рассчитанная дата `effectiveFrom`.
- Добавлен regression test сценария УСН/НДС с доходом 350 млн ₽ и разными датами регистрации.
- Layout fixtures обновлены под фактический 0.9.17 UI.

## Что намеренно не менялось

- Applicability evaluator и seed rules не переписывались ради UX.
- `region` остаётся nullable string, потому что ни одно текущее правило seed-37 не зависит от региона.
- `taxRegime` остаётся `USN | OSNO | other`; объект УСН не создаётся без правила, которому он действительно нужен.
- Архитектура, database migrations, bot 0.9.15 и feed semantics 0.9.16 сохранены.
- `.env` не менялся.
