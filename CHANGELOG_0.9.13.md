# Changelog 0.9.13

## UX/UI

- Проведён полный copy/interaction pass пользовательской mini-app для владельца бизнеса без юридической подготовки.
- Уточнены заголовки, статусы, пустые состояния, ошибки, подсказки и действия.
- Статус ручной проверки упрощён до «Нужно проверить вручную»; повторяющееся объяснение заменено прямым блоком «Что сделать сейчас».
- Основной регион переформулирован как обычный вопрос о работе бизнеса.
- Детальная карточка сохраняет контекст возврата: проверки / изменения / документы / история.
- Источники оформлены как читаемые карточки-ссылки вместо технических URL.
- В профиль добавлена корректная dirty-state логика: после сохранения кнопка disabled и не создаёт ложного ощущения несохранённых изменений.
- Документы, настройки и динамические действия визуально и текстово разделены; self-report не называется автоматической проверкой.
- Исправлены тексты refresh/error состояний и закрытие сообщений.
- Review UI приведён к той же светлой визуальной системе без изменения review semantics.

## Plain-language safety

- Добавлена нормализация известных manual-review причин в пользовательский русский текст.
- Усилены tests, запрещающие machine vocabulary в пользовательских полях/checklist и проверяющие читаемые состояния результата.
- LLM automation instructions требуют понятный русский для владельца малого бизнеса, запрещают field keys/JSON/Markdown и вопросы, требующие интерпретировать закон.

## Layout/accessibility

- Единая шкала отступов и card gap.
- Проверяются одинаковые края/ширины повторяющихся карточек и полей, вертикальные интервалы, touch targets и mobile navigation.
- Добавлены сценарии 320/375/768/1024/1440, включая long-text stress.
- User layout: 80/80; финальный targeted copy/layout pass: 30/30; review layout: 5/5.
- Основные цветовые пары проходят WCAG AA для обычного текста.

## Tests

- Offline core: 92/92.
- TS/TSX syntax: 98 файлов, 0 ошибок.
- Browser regression selectors обновлены под фактические 0.9.13 labels/buttons.
- Полный React/Vite/Docker acceptance необходимо повторить на Windows; `npm ci` в среде подготовки не завершился в доступное время.

## Preservation

- `.env` не изменён.
- `seed/v1` не изменён.
