# Изменения 0.9.10

## Пользовательский интерфейс
Переработан основной frontend: три раздела, отдельный экран результата, readable copy, вопросы с подсказками, явное неизвестное значение, аккуратные ошибки. Административный `/review` сохранён.

При ответе новая оценка заменяет старую в открытом экране без сброса навигации. Профиль сохраняется по кнопке; stale draft не перетирает свежие данные. Добавлено исправление ранее известных фактов в пределах нужного правила. Новые датированные нормы не называются текущим нарушением.

## Проверка документов
Добавлены 12 пилотных шаблонов документов/настроек и точки расширения через action-план нового правила. `business_check_answers` хранит неизменяемые, идемпотентные отметки. Их основание включает правило, контекст расчёта и объект бизнеса. Отметка не является юридическим заключением.

## Пересчёт и данные
Исправлен пересчёт после новой агрегированной версии профиля: несвязанные карточки не должны выпадать из current results. Динамическая дата читается из вложенного факта. SQL DATE остаётся календарной строкой. Вопрос об объекте предшествует вопросу о его показателях. Обновлена обработка актуальности action-плана.

## Лента
Неприменимая будущая норма не попадает в персональную подборку. Нет подстановки даты вступления в силу вместо даты поступления/публикации.

## Источники
Ограничены redirects, размер ответа, попытки и полное время загрузки. Учтены кодировки, неправильные HTML-сущности и даты. Добавлен native PDF text layer. Сканы и избыточный объём не превращаются в выдуманный/обрезанный текст. Номер/орган/дата из серверных метаданных проходят в immutable source snapshot. Добавлен административный retry extraction.

## Проверки и запуск
Новый dependency-light набор, browser regression, CSS fixtures, PostgreSQL usability integration и изолированный Compose acceptance. Подробный статус в TEST_REPORT.md: full build/DB/live не запускались успешно в среде подготовки.

## Сохранено
`.env` и все файлы seed/v1 побайтно соответствуют исходному ZIP. Существующие версии правил, профили, история, review/publication architecture и MAX-интеграция не заменены новым проектом.
