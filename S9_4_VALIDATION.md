## Смысловые замечания после чтения полного JSON

Прохождение gate не означает юридическую готовность. В этом черновике нужно проверить и исправить:

1. `validTo` первых двух этапов повторяет начала следующих. Основание прекращения не установлено; API возвращает `PHASE_END_MATCHES_ANOTHER_START`.
2. Условия о договоре и категории банка частично находятся в тексте без отдельных машинных условий. Перед созданием DSL нужно проверить полноту связки условий.
3. Исключение для торговой точки сформулировано как исключение для продавца; проверить объект применения порога и учесть разъяснения о подписках.

Часть этих проблем нельзя устранить проверкой дословности цитат. Публикация multi-phase candidate через прежний endpoint одного правила заблокирована до следующего review workflow.
