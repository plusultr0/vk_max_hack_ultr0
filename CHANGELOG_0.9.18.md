# 0.9.18 — убрать дублирующий блок ответов из карточек

## Что изменилось

- Из каждой пользовательской карточки требования полностью удалён блок «Ваши ответы, которые повлияли на результат».
- Вместе с заголовком удаляется весь список пар «поле → ответ» (например, система налогообложения, доход, дата расчёта и т. п.).
- Логика расчёта применимости, уточняющие вопросы, «Исправить ответы», действия, статусы и официальные источники не менялись.
- Удалены больше не используемые стили `facts-used`; layout fixtures приведены к фактическому UI.
- Добавлена offline-проверка, что этот блок нельзя случайно вернуть в `ImpactDetail`.
- `.env` не менялся.
