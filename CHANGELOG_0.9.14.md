# Changelog 0.9.14

Дата: 27.09.2026.

## UX

- Удалён лишний верхний поясняющий текст.
- Onboarding: один progress `Вопрос N из 8`, без повторяющихся номеров групп; увеличен отступ перед вопросом.
- `not_applicable`: customer copy говорит «требование не относится к вашему бизнесу», без внутренней формулировки «эта проверка».
- Причины применимости/неприменимости и детали карточки переименованы в язык нормативного требования.

## Выполнение требований

- Applicable card получила отдельный блок `Статус выполнения`.
- Добавлены состояния `Требования выполнены` / `Требования ещё не выполнены` и прогресс обязательных действий.
- Сохранена существующая `action_items.execution_status`; новая таблица law-level состояния не добавлялась.
- UI явно объясняет, что completion — self-report пользователя, не автоматическое юридическое заключение.
- Кнопка action: `Отметить выполненным`.

## Seed / domain

- Начальная база расширена с 7 до 37 требований.
- 30 новых правил: 13 ПДн, 12 торговля/права потребителей, 2 ККТ, 3 УСН/НДС.
- Добавлены `applies` / `not_applicable` / `needs_info` fixtures для каждого нового правила.
- Добавлены 39 dynamic fact definition versions для новых условий и self-report полей.
- Актуализированы потребительские сроки по Единым правилам Союзного государства: ремонт 14 дней, замена 7/14 дней, денежные требования 7/14 дней.
- Для дистанционной торговли использован действующий с 01.09.2026 нормативный слой, включая постановление Правительства РФ №657.

## Seed runtime

- Seed-loader переиспользует `installFactDefinitions` и `registerRuleDependencies`, чтобы clean seed мог установить dynamic fact registry и зависимости до использования новых правил.

## Tests

- Offline core suite расширен до **186/186**.
- Добавлены проверки 37 rules и 30 × 3 scenario fixtures.
- Добавлены section-14 UX regression assertions.
- Dynamic facts consistency: 39 definitions, 0 conflicts/binding errors.
- Static user layout: 80/80; admin review: 5/5.

## Environment

- `.env` не изменён; побайтно совпадает с входным 0.9.13.
- Docker acceptance не запускался: Docker CLI отсутствует в среде.
- Fresh npm dependency install заблокирован DNS `EAI_AGAIN`, поэтому full typecheck/build/React runtime здесь не заявляются пройденными.
